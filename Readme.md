##  Tentang Repository

Repository ini berisi kumpulan **praktikum mata kuliah Pengembangan Aplikasi Web (PAW)** yang mencakup pembelajaran fundamental pengembangan web modern. Materi disusun secara sistematis mulai dari **struktur halaman web (HTML)**, **styling dan desain (CSS)**, hingga **interaktivitas (JavaScript)**.

Setiap modul dilengkapi dengan:
-  **Materi teori** dan contoh kode
- 💻 **Source code** yang siap dijalankan
- 📝 **Tugas praktikum** untuk mengasah kemampuan
- 🚀 **Deployment** ke platform hosting modern

## 🚀 Cara Menjalankan

### 1️⃣ Clone Repository
```bash
git clone https://github.com/ValenNz/pengembangan-aplikasi-website.git
cd pengembangan-aplikasi-website
```

### 2️⃣ Buka dengan Visual Studio Code
```bash
code .
```

### 3️⃣ Install Extension Live Server
1. Buka VS Code → Extensions (Ctrl+Shift+X)
2. Cari **"Live Server"** by Ritwick Dey
3. Klik **Install**

### 4️⃣ Jalankan dengan Live Server
- Klik kanan pada file HTML → **"Open with Live Server"**
- Atau klik **"Go Live"** di status bar kanan bawah
- Browser akan otomatis terbuka di `http://127.0.0.1:5500/`

### 5️⃣ Testing Responsive Design (Modul 02)
1. Buka browser → Tekan **F12** (DevTools)
2. Klik **Toggle Device Toolbar** (Ctrl+Shift+M)
3. Pilih device: **iPad** (768px) atau **iPhone** (375px)
